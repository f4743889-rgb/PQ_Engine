# Регресійні тести Engine

| Що | Опис |
| --- | --- |
| fixtures\ | 21 тестовий файл (C… — CSV, X… — Excel і непідтримуваний формат, N01 — файл без схеми), кожен із відомим результатом |
| test_config.xlsx | Призначення, реєстр, схема, фільтри й очікування тестової книги (аркуші «Реєстр», «Схема», «Фільтри», «Призначення», «Очікування», «Навантаження») |
| queries\ | Тестові запити test_*.pq (test_All збирає 11 наборів) |
| gen_fixtures.py | Генератор fixtures\ і test_config.xlsx |

## Як підготувати тестову книгу з репозиторію

1. Скопіюйте робочу книгу **поза репозиторій** (наприклад, D:\EngineTests\TEST_PQ_ENGINE.xlsm).
2. Редактор VBA (Alt+F11) → File → Import File: `powerquery\vba\modSetupTestEngine.bas` (і modEngineCommon, якщо його ще немає).
3. Запустіть SetupTestEngine (Alt+F8) і виберіть **корінь клону репозиторію**. Макрос розпізнає структуру репозиторію:
   бере конфігурацію з tests\test_config.xlsx, фікстури з tests\fixtures, запити Engine з powerquery\queries і тести з tests\queries.
   Якщо не знайдено жодного .pq або немає test_All, він зупиняється з помилкою.
4. Дані → Оновити все. На аркуші «Тести» таблиця test_All: кожен рядок — PASS.
   Деталі FAIL — у test_Summary і test_Load (вони лише підключення; тимчасово завантажте потрібний на окремий аркуш).
5. Збережіть книгу і запустіть UpdateHelp. ExportPowerQueriesToRepo у тестовій книзі не запускайте (він і сам зупиниться).

Той самий макрос працює і з пакетом Engine (теки engine, test_engine).

## Фікстури і генератор

`python gen_fixtures.py <тека>` створює `<тека>\fixtures\` і `<тека>\test_config.xlsx` (потрібен openpyxl).
Аркуш «Інструкція» в test_config.xlsx — текст цього README.
CSV виходять байт у байт однаковими; файли .xlsx — з іншою датою створення всередині, тож Git покаже їх зміненими,
хоча вміст той самий. Тому перегенеровувати лише тоді, коли змінився сам генератор, і комітити генератор і файли разом.
Фікстури навмисно мають різні кодування, закінчення рядків і «пошкоджені» файли: .gitattributes зберігає їх байт у байт.

## Як додати сценарій

Новий блок у gen_fixtures.py (файл, рядок реєстру, очікування) → перегенерувати → SetupTestEngine у тестовій книзі.
Код запитів Engine не змінюється. Новий тестовий запит — файл у queries\ і рядок у test_All.
