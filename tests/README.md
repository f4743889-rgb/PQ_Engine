# Регресійні тести Engine: фікстури

**fixtures\\** — 21 тестовий файл (C… — CSV, X… — Excel і непідтримуваний формат, N01 — файл без схеми).
Кожен сценарій має відомий результат; очікування записано в test_config.xlsx (аркуші «Очікування», «Навантаження»)
і в тестовій книзі (tblTestExpected, tblTestLoad).

**test_config.xlsx** — призначення, реєстр, схема, фільтри й очікування тестової книги.

**gen_fixtures.py** — генератор усіх цих файлів: `python gen_fixtures.py <тека>` створює `<тека>\fixtures\` і `<тека>\test_config.xlsx`
(потрібен openpyxl). CSV виходять байт у байт однаковими; файли .xlsx — з іншою датою створення всередині, тож Git покаже їх зміненими,
хоча вміст той самий. Тому перегенеровувати лише тоді, коли змінився сам генератор, і комітити генератор і файли разом.

Фікстури навмисно мають різні кодування, закінчення рядків і «пошкоджені» файли: .gitattributes зберігає їх байт у байт.

## Як підготувати тестову книгу

Тестову книгу готує макрос SetupTestEngine з **пакета** Engine (теки engine і test_engine), а не з цього репозиторію:
SetupTestEngine шукає test_engine\fixtures і engine\powerquery у вибраній теці. Порядок — у test_engine\README_stageC.md пакета
і в docs\architecture (розділ 6.11).

## Як додати сценарій

Новий файл у fixtures (краще — новий блок у gen_fixtures.py), рядок у реєстрі й очікування в test_config.xlsx,
потім SetupTestEngine у тестовій книзі. Код запитів не змінюється.
