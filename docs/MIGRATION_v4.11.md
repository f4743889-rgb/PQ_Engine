## 5. Тексти довідок у книзі (hlp-таблиці й каталог)

Заміни для колонки «Призначення та Логіка» / «Призначення та Опис» (третя колонка). Текст у курсиві й дужках — пояснення для вас, у клітинку його не переносити.

hlpSourceRegistry, рядок ErrorPolicy, колонка «Тип даних / Валідація»: `Text` без пробілу в кінці.

**hlpSourceRegistry**

| Колонка | Новий текст |
| --- | --- |
| FullPath (ПовнийШлях) | Повна адреса файлу. Має пріоритет над Path + FileName (fn_SourcePath). Макрос SelectSourceFiles записує FullPath і очищає Path і FileName цього рядка. |
| *новий рядок* Delimiter | Роздільник CSV для цього джерела (наприклад, ; або ,). Порожньо — cfgSettings[CsvDelimiter]. |
| *новий рядок* Encoding | Кодова сторінка CSV: 65001 (UTF-8) або 1251. Мітка BOM у файлі має пріоритет. Порожньо — cfgSettings[CsvEncoding]. |
| *новий рядок* Culture | Культура розпізнавання чисел і дат під час типізації (наприклад, uk-UA). Порожньо — cfgSettings[Culture]. |
| ErrorPolicy | Рівень суворості обробки помилок (Strict, Report, Lenient), опис — у tblErrorPolicy. Порожньо — cfgSettings[ErrorPolicy]. Задається лише тут або в cfgSettings. |
| ErrorThreshold | Поріг частки рядків з помилками (лише для Report і Lenient). Порожньо — cfgSettings[ErrorThreshold]. Допустимі значення — у hlpErrorThreshold. |

Для нових рядків колонка «Тип даних / Валідація»: Delimiter — Text (опційно); Encoding — Number (опційно); Culture — Text (опційно).

**hlpSchemaRegistry**

| Колонка | Новий текст |
| --- | --- |
| TrimFlag | Якщо TRUE, Power Query виконає Text.Trim + Text.Clean для цієї колонки після завантаження. |
| CustomTransform | Назви дій з tblCustomTransform; кілька дій розділяються символом ; (наприклад, Upper;NullToZero). TrimFlag — окрема колонка схеми, а не дія. Невідома назва дає помилку НевідомеПеретворення (pq_SchemaCheck). |

**hlpErrorThreshold** — додати рядок у кінець:

| Що вписано | Тип у клітинці | Результат |
| --- | --- | --- |
| Коли діє поріг | — | Лише для ErrorPolicy = Report і Lenient (Strict зупиняє за будь-якої помилки). Завантаження зупиняється (ПеревищенийПоріг), коли частка рядків з помилками **більша** за поріг; частка, що дорівнює порогу, проходить. |

**tblTableCatalog, «Призначення» рядка hlpErrorThreshold:** «Довідник допустимих значень колонки ErrorThreshold і результату, який вони дають.» (замість злиплого «ErrorThresholdта»).

## 6. Описи запитів (з v4.11 потрапляють у queries.yml і README)

Редактор Power Query → правою кнопкою на запиті → Властивості → Опис:

| Запит | Новий опис |
| --- | --- |
| cfgTypeMap | Карта типів даних: значення DataType схеми → тип M |
| cfgTransforms | Білий список дій CustomTransform. Stage визначає, до чи після типізації виконується дія. Нові дії додавати лише тут. Назви дій у схемі порівнюються без урахування регістру |
| fn_SourcePath | Шлях до файла рядка реєстру: FullPath або Path + FileName |
| fn_ToRate | Розбір ErrorThreshold: число, відсоток або текст → частка 0..1, off → вимкнено |

Решту описів перегляньте за списком у `powerquery\README.md` після експорту.
